# Personal Portfolio

Vokhobjonov Biloldinning shaxsiy portfolio saytim — HTML, CSS va JavaScript asosida yaratilgan, responsiv dizaynga ega uch sahifali veb-sayt.

## Loyiha haqida

Bu loyiha frontend web-development kursi doirasida yaratilgan bo'lib, HTML semantikasi, CSS Box Model, Flexbox, Grid, Media Queries, JavaScript DOM manipulyatsiyasi, hodisalar (events) va forma validatsiyasi kabi mavzularni o'zida mujassam etadi.

## Sahifalar

- **index.html** — Bosh sahifa: profil ma'lumotlari, texnologiyalar ro'yxati va interaktiv Counter mini-dasturi
- **about.html** — Men haqimda sahifasi: ko'nikmalar (skill bars) va belgilar sanagichi (character counter)
- **contact.html** — Kontakt sahifasi: aloqa formasi (validatsiya bilan) va ijtimoiy tarmoqlar

## Texnologiyalar

- HTML5 (semantik teglar)
- CSS3 (Flexbox, Grid, Media Queries, pseudo-klasslar/elementlar)
- JavaScript (Vanilla JS — DOM, hodisalar, forma validatsiyasi)
- Vite — dasturlash muhiti va build tool
- ESLint — kod sifatini nazorat qilish

## Interaktiv funksiyalar

1. Counter (index.html) — sanagich; qiymat 0 bo'lganda kamaytirish va qaytarish tugmalari avtomatik disabled bo'ladi
2. Character Counter (about.html) — matn maydoniga yozilgan belgilar sonini real vaqtda hisoblaydi
3. Contact Form Validation (contact.html) — barcha maydonlar to'ldirilganini va email formati to'g'riligini tekshiradi
4. Mobile Navigation — barcha sahifalarda ishlaydigan responsiv burger-menyu

## O'rnatish va ishga tushirish

1. Repozitoriyani klonlang: git clone https://github.com/Vakhobjonooov/Personalportfolio.git
2. Papkaga kiring: cd Personalportfolio
3. Paketlarni o'rnating: npm install
4. Development serverini ishga tushiring: npm run dev
5. Production uchun build qiling: npm run build
6. Kodni ESLint bilan tekshiring: npm run lint

Yoki oddiygina index.html faylini brauzerda oching, yoki VS Code'da Live Server extension orqali ishga tushiring.
